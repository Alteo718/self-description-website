# Personal Portfolio Website

My personal portfolio site showcasing my background, skills, and projects as a recent Computer Engineering graduate pursuing a career in front-end/web development.

**Live site:** https://deft-douhua-f853e7.netlify.app/

## What it includes

- About/intro section
- Skills overview (HTML, CSS, JavaScript, React, Node.js)
- Project showcase with links to live demos
- Downloadable CV
- Contact form

## Tech Stack

- HTML, CSS, JavaScript, React
- Deployed on Netlify

## Running locally

```bash
git clone https://github.com/Alteo718/[your-portfolio-repo-name].git
cd [repo-folder]
npm install
npm start
```
